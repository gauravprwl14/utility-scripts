# Quick Setup Guide

## 🚀 Get Started in 3 Steps

### 1️⃣ Install Tampermonkey
- Visit: https://www.tampermonkey.net/
- Install the extension for your browser

### 2️⃣ Add the Script
1. Open `chrome-extension-transcript.js`
2. Copy all the code
3. Click Tampermonkey icon → "Create a new script"
4. Paste the code
5. Save (Ctrl+S)

### 3️⃣ Use It!
1. Go to: https://www.longcut.ai/analyze/ryGJLXruUxs?url=https%3A%2F%2Fwww.youtube.com%2Fwatch%3Fv%3DryGJLXruUxs
2. Look for the **Copy** button next to **Export**
3. Click it!
4. Paste anywhere (Ctrl+V) to see the JSON
