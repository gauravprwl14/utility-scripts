# plot.md — yt-transcript-extractor

Node.js CLI that extracts YouTube transcripts, metadata, and AI analysis via the Longcut.ai API. Outputs structured Markdown notes with timestamped transcripts and maintains an Obsidian-compatible index. Includes a companion Tampermonkey userscript for browser-based extraction.

**Stack**: Node.js, axios, dotenv | **Entry**: `node main.js --url=<youtube_url>`
